# test01

Nuxt 4 + TypeScript のスターターです。パッケージマネージャは pnpm です。

## 公開 URL

Vercel プロジェクト `test01` で公開しています。

- https://test01-tau-swart.vercel.app

`main` への push で Production が更新されます。

## セットアップ

Node.js 22 以上が必要です。

```bash
pnpm install
```

## 開発サーバー

`http://localhost:3000` で起動します。

```bash
pnpm dev
```

## ビルド

```bash
pnpm build
```

その他:

```bash
pnpm lint
pnpm typecheck
```
